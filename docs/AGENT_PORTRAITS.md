## UI behavior

The shared `AgentAvatar` component selects only known local assets. CEO and RJ share the lion. Existing labels remain visible and are the accessible identity; decorative images have empty alt text. Unknown agents and failed images fall back to initials. Portraits do not request external URLs or depend on a model call at runtime.
